# Job Portal Application

A full-stack job portal built with React, Node.js, Express, and MongoDB.

## Features

### Admin
- Login
- Add/Update/Delete Jobs
- View all job applications
- Approve/Reject candidates

### Users
- Registration & Login
- View available jobs
- Apply for jobs
- View applied jobs

## Tech Stack
- Frontend: React + Tailwind CSS
- Backend: Node.js + Express
- Database: MongoDB
- Auth: JWT
- Password Security: bcrypt
- API: REST API

## Setup

### Backend
1. cd backend
2. npm install
3. Create .env file with MONGO_URI and JWT_SECRET
4. npm start

### Frontend
1. cd frontend
2. npm install
3. npm start

## Usage
- Register as user or login as admin (create admin manually in DB)
- Admins can manage jobs and applications
- Users can browse and apply for jobs
